
AI Agent will call to MCP gateway to get the 
data and then process it accordingly. The data will
be fetched in JSON format and parsed to extract relevant information. The agent will then perform necessary computations and return the results back to the user.

MCP gateway listning at http 5000

Flow is like below

     AI AGENT -> MCP GATEWAY -> MCP SERVER -> API END POINTS    

a. AI Agent sends a request to MCP gateway at http://localhost:5000 with necessary parameters.	
b. MCP gateway receives the request and processes it to fetch the required data from the database or external sources.	
c. MCP gateway returns the data in JSON format to the AI Agent.

E. AI Agent will then send the tools list to LLM for further processing and decision making.    
G. LLM will analyze the tools list and determine which tools are relevant for the user's request. It will then provide instructions to the AI Agent on how to use the selected tools to fetch and process the required data.    
H.  AI Agent will follow the instructions provided by LLM to call the relevant tools from the MCP gateway, fetch the necessary data, and perform any required computations or processing.   
i.  Once LLM tell wtools to use, AI Agent will call the tools from MCP gateway and get the data in JSON format.
